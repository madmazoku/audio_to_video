Compatibility note:

Compact output limits:
- String fields max 12 words each.
- Arrays max 3 items; identity_anchors_to_show max 1.
- Each array item max 6 words.
- No explanations, prompt prose, copied lyric lines, or alternate plans.

Priority order:
1. Current subrange text.
2. Full range text if subrange is sparse.
3. Bracket directives as mood/section metadata only.
4. Song context and identity contract as low-priority inventory/design lens.
5. Style contract as medium/look only.
6. Previous visuals for consistency only, never as a scene template.

Lyric grounding:
- main_subject and main_action must come from current lyrics/range meaning.
- If lyrics imply a group, use a group subject; do not collapse it into one iconic character.
- If lyrics name or imply a setting/path/environment, that local setting wins.
- Concrete global anchors may be central only when current lyrics mention or clearly imply them.
- must_show contains only elements grounded in current subrange/range lyrics.
- identity_anchors_to_show defaults to [] and may contain only one local supporting anchor that directly helps the lyric event.
- Do not copy concrete anchors from contracts, song context, or previous visuals into main_subject, setting, must_show, destination, or composition center without lyric support.
- Treat malformed concrete continuity requirements as optional inventory only.
- Put over-dominant unsupported anchors into avoid_as_main_subject.

Single-shot planning:
- Plan one continuous visible event: one subject/group, one place, one dominant lighting/color grade, one action path.
- No internal montage, cut, scene jump, late new destination, or final tableau reveal.
- visual_consequence must be a direct changed state inside the same scene.
- Avoid idle pose, mood board, abstract atmosphere, or camera-only action.
